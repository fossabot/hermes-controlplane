# Screenshots

Drop your screenshots here. Recommended format: PNG, ~1400px wide.

## Required files (referenced from the root README)

| File | What to capture | Notes |
|------|----------------|-------|
| `overview.png` | Global overview page (`/`) | KPIs + charts, clean data |
| `sessions.png` | Sessions list page (`/sessions`) | Show the table + filters |
| `session-detail.png` | A single session detail page (`/sessions/{id}`) | Message preview + token breakdown |
| `cron.png` | Cron jobs page (`/cron`) | Table with at least one example job + action buttons |

## Tips for clean screenshots

- Use a fresh browser window with dev tools closed.
- Replace any sensitive model names, API URLs, or token values with dummy data if needed.
- Keep the window wide enough (~1400 px) so the layout looks good in the README preview.
- Avoid showing personal profile names if you prefer not to; use generic names like `radar` and `webhook`.
